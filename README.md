# Design-and-Simulation-of-4-bit-processor
4-bit architectures are largely obsolete in modern systems, they serve as educational models

INTRODUCTION
The design of processors forms the foundation of modern digital systems and embedded
applications. This project presents the design and simulation of a 4-bit processor using
VHDL. The proposed processor consists of essential components such as an Arithmetic
Logic Unit (ALU), register file, control unit, and memory, which work together to
execute basic arithmetic and logical operations. The processor is designed to perform
operations including addition, subtraction, AND, OR, and XOR based on a simple
instruction set. VHDL is used to model the processor architecture, and the design is
verified through behavioral simulation using Xilinx Vivado. Simulation results
demonstrate the correct execution of instructions and validate the functionality of
individual modules. The proposed 4-bit processor provides a simple and efficient
platform for understanding processor architecture and digital system design. Furthermore,
it serves as a foundation for developing more advanced processors for embedded and
real-time applications.
